Design a complete mobile UI (iOS & Android, 390×844 pt) for an Offline-First Local Skill Swap Marketplace app.

App concept: People within walking distance trade skills for free (barter only). Strong focus on trust, safety, and seamless offline use.

Design System to follow strictly:
- Warm, human, neighborhood feeling
- Primary color: Warm Teal #0F766E
- Accent: Soft Coral #F97066
- Background: Warm Off-White #FAF9F6
- Cards: White with 16pt radius and very soft shadow
- Typography: Inter / SF Pro, clear hierarchy
- Large touch targets, generous spacing (16–20pt margins)
- Always visible offline status

Key Screens & User Flows to design (in order):

1. Onboarding (3–4 screens)
   - Welcome + value prop
   - Location permission with clear benefit explanation
   - Create profile (photo, name, short bio)
   - Add skills offered + skills wanted (chips + optional short video)
   - Set default radius and availability

2. Home / Nearby Feed (main screen)
   - Top: Offline/Online status banner
   - Search bar + radius selector
   - Vertical list or map+list toggle of nearby people
   - Each card: Avatar, name, distance, rating, 2–3 skill chips, “Request Swap” button
   - Floating or bottom “Offer a Skill” action

3. Profile Detail
   - Large avatar, name, verification badge, rating, response rate
   - Skills offered & wanted sections
   - Short video demos if available
   - Safety info + “Request Swap” primary CTA
   - Past swap highlights (optional)

4. Request Swap Flow
   - Select which skill you want from them
   - Select which skill you offer
   - Short message + preferred times
   - Confirmation screen with safety tips
   - Success state

5. Requests / Activity Tab
   - Incoming / Outgoing / Completed segments
   - Clear status pills
   - Quick actions (Accept, Counter, Message, Mark Complete)

6. Chat / Messaging
   - Clean conversation view
   - Offline queue indicator when messages are pending
   - Quick safety actions (Share live location, Report)

7. Swap Completion & Rating
   - Mark complete
   - Mutual rating (stars + optional note)
   - Success / reputation update animation

8. Profile & Settings
   - Own reputation dashboard
   - Standing offers management
   - Safety & verification settings
   - Offline data management

Additional required elements:
- Persistent offline banner when no connection
- Empty states that feel friendly and helpful
- Loading skeletons that match the warm style
- Bottom tab bar: Nearby • Requests • Messages • Profile
- Clear visual distinction between online and offline content

Style references: Warm like Airbnb + clean utility of Linear + trustworthy like Nextdoor, but lighter and more human. Avoid dark mode for the primary designs unless specified.

Deliver: High-fidelity mobile screens for the full flow above, consistent components, and a simple design system page showing colors, type, and key components.
